# Whole-Letter Structure and Opening

Read this file only when the user asks to organize, draft, or audit a complete response package. The skill's default task remains one explicitly selected comment or a small set of closely related comments at a time. Read `response-templates.md` separately when an individual response needs a conditional pattern.

## Organize the complete response clearly

- Begin with a brief opening that appreciates the editor and reviewers, states that the comments improved the manuscript, and summarizes the most important changes.
- Usually identify three to five major revisions; omit minor edits from the opening.
- Unless instructed otherwise, order responses as editor comments, Reviewer 1, Reviewer 2, Reviewer 3, and so forth.
- Reproduce each comment in full unless the journal or editor instructs otherwise.
- Visually distinguish comments from responses.
- Number comments consistently and use the same numbering system throughout.
- Do not combine separate comments merely because they share a topic.
- Cross-reference related responses when helpful, while still answering each comment locally.

## Opening-letter elements

Include, when accurate and appropriate:

- appreciation for the editor and reviewers;
- a brief statement that the revision improved the manuscript;
- a concise summary of major changes;
- a statement that the authors respond point by point.

Conditional template:

> Dear [Editor Role] and Reviewers:
>
> Thank you for the thoughtful and constructive feedback on our manuscript. We carefully considered each comment and substantially revised the manuscript. The revision includes [three to five] major changes. First, [major conceptual change]. Second, [model, mechanism, or boundary change]. Third, [major empirical change]. Fourth, [claim recalibration or limitation change]. We believe these revisions have strengthened the manuscript. Below, we reproduce each comment and respond point by point.

Use only changes that are verified and genuinely major.
