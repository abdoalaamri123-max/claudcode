# Main Manuscript Versus Supplemental Material

Read this file whenever an individual response adds, relocates, or discusses an analysis, measure, model, table, figure, coding detail, stimulus, or other evidence.

Keep analyses central to the manuscript's claims in the main text. Do not move theoretically essential evidence to the Online Supplemental Materials merely to preserve space.

Use the Online Supplemental Materials for:

- detailed robustness analyses;
- alternative operationalizations;
- additional model specifications;
- full measurement information;
- auxiliary tables;
- extended coding procedures;
- additional stimuli;
- analyses that support but do not define the central contribution.

Explain why a particular analysis appears in the supplement. Summarize the result in the main manuscript when it matters to the argument.

Example:

> Because this analysis evaluates a secondary measurement concern rather than a central theoretical prediction, we report the complete results in Table X of the Online Supplemental Materials (p. XX in the Online Supplemental Materials). We summarize the result in the main manuscript (p. XX).
