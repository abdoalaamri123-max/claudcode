# 00 · 叙述 / 系统综述 / 元分析怎么选

> "我读了很多文献"不等于系统综述，更不等于元分析。**先分清三者，再判断你的研究能不能、该不该做统计合并。**

## 一、三者区别

| | 叙述性综述 narrative | 系统综述 systematic review | 元分析 meta-analysis |
| --- | --- | --- | --- |
| 检索 | 不系统、可选择性 | **系统、可复制**（PRISMA） | 系统（同左） |
| 筛选 | 主观 | 预设纳排标准、双人筛选 | 同左 |
| 合并 | 定性叙述 | 定性/结构化综合，**可不含统计合并** | **统计合并出总效应** |
| 偏倚 | 高 | 低（透明流程） | 低 + 定量偏倚检测 |

> 关键：**系统综述 ⊇ 元分析**。元分析是"系统综述 + 定量合并"。可以有系统综述而无元分析（研究太异质时），但严肃的元分析必须建立在系统综述流程上。

## 二、什么时候能做元分析（能不能合并）

元分析要求纳入研究足够**同质**、可比：
- **相似的研究问题/PICO**：人群、干预/暴露、对照、结局大致可比。
- **可提取的效应量**：每个研究能算出同类效应量（d/r/OR…）及其方差。
- **足够数量**：太少（如 2–3 个）合并意义有限（虽无硬下限，但要谨慎）。

**"apples and oranges" 批评**：把过于不同的研究合并，总效应无意义。回应：明确合并的层次（都在测"同一类"关系）、用随机效应承认差异、用亚组/元回归解释异质性。

## 三、什么时候不做（或谨慎）

- 研究在设计、测量、人群上**高度异质**，无共同可比效应 → 改叙述性/结构化综合。
- 纳入研究**太少**或质量太差 → 合并会放大偏倚。
- 结局无法转成统一效应量 → 无法合并。
- 存在**严重发表偏倚**且无法校正 → 合并值可能虚高。

## 四、几种综述家族（了解，别混用名号）

- 系统综述、元分析、**范围综述（scoping review）**（摸清领域范围，不合并）、**伞形综述（umbrella review）**（综述之综述）、快速综述、**元综合（meta-synthesis / 质性）**。
- 选对类型并用对应报告规范（PRISMA、PRISMA-ScR 等）。

## 五、决策清单
1. 我的检索/筛选是**系统可复制**的吗？（不是 → 先做成系统综述）
2. 纳入研究**足够同质**、能提取**同类效应量**吗？（是 → 可元分析）
3. 数量够吗？质量能接受吗？
4. 我预注册了吗（PROSPERO）？（见 `01`）
5. 我准备好报**异质性 + 发表偏倚 + 偏倚风险**了吗？
