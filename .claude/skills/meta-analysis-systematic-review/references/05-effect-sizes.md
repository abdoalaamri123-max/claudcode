# 05 · 效应量：选择、计算、换算

> 元分析合并的是**效应量**，不是 p 值。据结局类型选对效应量、方向统一、方差正确，是合并的前提。

## 一、常用效应量

| 结局类型 | 效应量 | 说明 |
| --- | --- | --- |
| 连续（两组均值差） | **Cohen's d / Hedges' g** | g 是 d 的小样本偏差校正版，元分析**首选 g** |
| 连续（相关） | **Pearson r**（常转 Fisher's z 合并） | 相关研究常用 |
| 二分（比值） | **OR（比值比）/ RR（风险比）/ RD** | 医学/流行病学常用，OR/RR 常取对数合并 |
| 单组前后 | 标准化均值变化 | 注意前后测相关 |

## 二、关键公式与要点

- **Cohen's d** = (M₁ − M₂) / SD_pooled。
- **Hedges' g** = d × J（J≈1 − 3/(4df−1)，小样本校正）。**报告用 g。**
- **Fisher's z** = 0.5 × ln[(1+r)/(1−r)]，合并后再转回 r 报告（r 的抽样分布偏态，z 更适合合并）。
- **对数 OR/RR**：合并在对数尺度进行，结果指数化报告。
- 每个效应量都要有**方差/标准误**（逆方差加权用，见 `06`）。

## 三、换算（从可得统计量算效应量）

常需从 t、F、p、r、OR、均值/SD 之间换算，例如：
- 由 t 与 n：d = 2t/√df（独立两组近似）。
- r ↔ d 互换：d = 2r/√(1−r²)；r = d/√(d²+4)。
- OR ↔ d（Logistic 近似）：d = ln(OR)×√3/π。
- 工具：`esc`、`compute.es`、`metafor::escalc()`（R）会自动换算并给方差。

## 四、方向统一（极易出错）

- 合并前把所有效应量调成**同一方向**（如"正值=干预更好/正相关"）。
- 反向计分的量表、对照与干预颠倒的研究要翻转符号。
- 漏做方向统一 → 合并值被抵消，结论错误。

## 五、选哪个效应量的原则

- **与结局类型匹配**：连续用 g，相关用 r/z，二分用 OR/RR。
- **全体研究可统一**：能换算成同一种效应量才可合并。
- 报告时**说明选择理由与换算方法**。

## 六、常见误区
- ❌ 合并 p 值而非效应量。
- ❌ 用 d 不做小样本校正（应报 g）。
- ❌ 相关直接合并 r 不转 Fisher's z。
- ❌ 忘记方向统一。
- ❌ 换算不报方法，方差算错。
