# 08 · 发表偏倚检测

> 阳性、显著的结果更容易发表 → 元分析纳入的研究可能系统性偏向大效应，合并值虚高。必须检测并尽量校正。

## 一、发表偏倚是什么

- **发表偏倚**：不显著/小效应研究被压在抽屉里（file-drawer）。
- 相关问题：小研究效应（small-study effects）、选择性结局报告、语言偏倚、时滞偏倚。
- 后果：合并效应**高估**。

## 二、检测方法

| 方法 | 做什么 | 注意 |
| --- | --- | --- |
| **漏斗图 funnel plot** | 效应量 vs 精度（SE）散点，看是否对称 | 主观；不对称≠一定是发表偏倚 |
| **Egger 回归检验** | 定量检验漏斗图不对称 | 研究少（<10）时功效低、慎用 |
| **Begg 秩相关** | 另一种不对称检验 | 功效更低 |
| **Trim-and-fill** | 估计并"填补"缺失研究，给校正后合并值 | 是敏感性分析，不是真值 |
| **Fail-safe N** | 需多少个零效应研究才能翻转结论 | 已不推荐单独作为证据 |
| **p-curve / p-uniform** | 分析显著 p 值分布，判断是否有真效应/p-hacking | 心理学近年常用 |
| **PET-PEESE** | 回归法校正小研究效应 | 有争议，作敏感性分析 |

## 三、怎么用

- **至少画漏斗图 + 一种定量检验（如 Egger，研究≥10）**。
- 用 **trim-and-fill / PET-PEESE / p-curve 做敏感性分析**，看校正后结论是否稳健。
- 结合**灰色文献检索**（`02`）从源头减少偏倚。

## 四、解读要谨慎

- 漏斗图不对称的原因**不止发表偏倚**：真异质、小研究质量差、机遇。别一看不对称就断定发表偏倚。
- 研究数少（<10）时所有检验都不可靠，如实说明局限。

## 五、报告
- 漏斗图 + Egger（含 p）+ 校正法结果。
- 明确：即使校正后结论是否改变、局限如何。

## 六、常见误区
- ❌ 完全不做发表偏倚检测。
- ❌ 研究很少却硬做 Egger 并当定论。
- ❌ 漏斗图不对称直接等同发表偏倚。
- ❌ 把 trim-and-fill 校正值当"真效应"。
