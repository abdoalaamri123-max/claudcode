# 11 · 案例库：元分析真实骨架

> **体例示范**，帮你把流程串起来。**数字为虚构示例，勿套用**；结论必须来自你的检索与数据。

## 案例 A · 心理干预元分析（连续结局）

- **问题（PICO）**：大学生（P）正念训练（I）对比候补对照（C）对焦虑（O）的效果，RCT（S）。
- **效应量**：Hedges' g（组间均值差）。
- **模型**：随机效应 REML；报 g、95%CI、I²、τ²、预测区间。
- **异质性**：I²=68% → 亚组（干预时长）+ 元回归（平均年龄）。
- **偏倚**：漏斗图 + Egger + trim-and-fill；RoB2 评质量；GRADE 中等。
- **对应**：`05`、`06`、`07`、`08`、`09`。

## 案例 B · 相关关系元分析

- **问题**：工作投入与工作绩效的相关。
- **效应量**：Pearson r → Fisher's z 合并 → 转回 r 报告。
- **模型**：随机效应。
- **调节**：行业、测量工具、国别（元回归）。
- **对应**：`05` 相关部分、`07`。

## 案例 C · 医学二分结局

- **问题**：某药 vs 安慰剂对某事件发生率。
- **效应量**：OR（对数尺度合并）。
- **工具**：RevMan / metafor；RoB2；GRADE。
- **对应**：`05` OR、`09`、`10`。

## 案例 D · 系统综述（不做元分析）

- **情形**：纳入研究设计/测量高度异质，无法合并。
- **做法**：PRISMA 系统检索与筛选 + **结构化叙述综合（narrative synthesis / SWiM）**，用表格归纳效应方向与质量，不给合并值。
- **对应**：`00` 能不能合并、`03` PRISMA。
