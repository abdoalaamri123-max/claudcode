# PRISMA 报告 + 结果写作清单（模板）

> 投稿前逐条核对（改编自 PRISMA 2020）。配套见 `references/10`。

## 标题与摘要
- [ ] 标题标明"系统综述"/"元分析"
- [ ] 结构化摘要（目的、方法、结果、结论、注册号）

## 引言
- [ ] 背景与依据
- [ ] 明确目标（PICO）

## 方法
- [ ] 纳入/排除标准
- [ ] 信息源（含日期）
- [ ] **完整检索式**（至少一个库，附录给全）
- [ ] 筛选流程（双人、工具、一致性）
- [ ] 数据提取项与流程
- [ ] 效应量定义与计算/换算
- [ ] 合并模型（固定/随机、τ² 估计器、HKSJ）
- [ ] 异质性评估（Q/I²/τ²/预测区间）
- [ ] 亚组/元回归计划（是否预设）
- [ ] 发表偏倚方法
- [ ] 偏倚风险工具（RoB2/NOS）与 GRADE
- [ ] 注册与协议（编号）

## 结果
- [ ] **PRISMA 流程图**（数字闭合）
- [ ] 纳入研究特征表
- [ ] 偏倚风险结果（traffic-light）
- [ ] 合并效应 + 95%CI + p + **森林图**
- [ ] I²/τ²/预测区间
- [ ] 亚组/元回归结果
- [ ] 发表偏倚（漏斗图 + Egger + 校正）

## 讨论
- [ ] 主要发现与证据强度（GRADE）
- [ ] 异质来源解释
- [ ] 局限（研究数、质量、偏倚）
- [ ] 对理论/实践的含义

## 其他
- [ ] 数据/代码可得性
- [ ] 资助与利益冲突
