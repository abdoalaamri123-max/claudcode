# Chapter 9: Multivariate Methods for Heterogeneous Data
*Source: Holmes & Huber, Modern Statistics for Modern Biology, https://www.huber.embl.de/msmb/09-chap.html*

## Core concepts
- Ordination (MDS/PCoA, CA, NMDS, t-SNE, diffusion maps) generalizes PCA to cases with no natural coordinates, only a (dis)similarity matrix. As clustering uncovers hidden **categorical** structure, ordination uncovers hidden **continuous** structure (gradients, "pseudotime", ecological gradients).
- Classical (metric) MDS / Principal Coordinates Analysis (PCoA): from a squared-distance matrix D∙D, double-center it — B = −½ H (D∙D) H, with centering matrix H = I − (1/n)**11**ᵀ — then eigendecompose B = UΛUᵀ and take X̃ = UΛ^(1/2). This is the exact algebraic inverse of going from coordinates to distances; it is the same machinery as PCA but starting from distances instead of a variable matrix.
- MDS/PCoA output has only one "mode" (the points) — unlike PCA there is no dual loadings/variables space, no biplot, no loading vectors. Interpretation relies on examining extreme points, not axis loadings.
- MDS/PCoA solutions are invariant to rotation and reflection of the map — axis sign/orientation is arbitrary and can differ between runs, platforms, or software without indicating any real difference.
- Non-metric MDS (NMDS): finds a transform f(d) of the dissimilarities and low-dim coordinates with distances d̃ so that f(d) ≈ d̃, using only the **rank order** of distances (robust to scale/outliers). Fit quality: stress² = Σ(f(d) − d̃)² / Σd². There is no "% variance explained" — use a Shepard plot (original vs. reconstructed distances) and a stress-vs-k curve instead.
- Robustness concept: breakdown point = fraction of data that must be corrupted to arbitrarily change an estimate. Median's breakdown point is 1/2; the mean's is only 1/n. Rank-based methods (NMDS, rank-threshold transforms) inherit this kind of robustness; ordinary (squared-distance) MDS does not.
- Correspondence analysis (CA): a weighted SVD/MDS for contingency tables (counts/co-occurrence), using **chi-square distance** in place of Euclidean distance/variance. Departure from independence: X² = Σ_{i,j} (n_ij − n_i·n_·j/n)² / (n_i·n_·j/n). CA decomposes this chi-square inertia into orthogonal axes exactly as PCA decomposes variance — report % of total inertia captured by displayed axes (e.g., a real hair/eye-color CA captured 89%+10%=99% of inertia in axes 1–2; an HIV-mutation co-occurrence table needed 3 axes, not 2).
- CA biplots are symmetric/barycentric: row points sit at the (weighted) center of gravity of column points, and vice versa — proximity of a row and column category is interpretable as co-occurrence strength, but this barycentric geometry does not apply to ordinary PCA/MDS biplots.
- Multiple correspondence analysis (MCA) extends CA to several categorical variables at once (continuous variables must first be discretized); see Pagès (2016) "Multiple Factor Analysis by Example Using R" — Multiple Factor Analysis (MFA) is the companion technique for weighting several tables of mixed types so that no single table (by virtue of having more variables or a different scale) dominates the joint analysis.
- Local/nonlinear methods (kernel MDS, t-SNE, diffusion maps, LLE, isomap, Laplacian eigenmaps) deliberately sacrifice accurate representation of large (far-apart) distances to represent local neighborhoods well — appropriate when the true structure is a curved manifold/gradient rather than a linear subspace, and when large distances are measured less reliably than small ones. A radial basis kernel example: 1 − exp(−d(x,y)²/σ²), which heavily discounts large distances.
- Diffusion maps build a Markov-chain transition-probability (affinity) matrix from local distances, then eigendecompose it — well suited to recovering developmental trajectories/pseudotime, more so than linear MDS.
- Multi-table generalizations of covariance: RV coefficient (matrix analog of correlation, in [0,1]): RV(A,B) = Tr(AᵀBABᵀ) / √(Tr(AᵀA)Tr(BᵀB)); Mantel coefficient (correlation between two distance matrices' vectorized entries), tested by permutation (not a classical p-value, because distance-matrix entries are not independent); Canonical Correlation Analysis (CCA, finds linear combinations U=Xa, V=Yb of two tables maximizing cor(U,V), subject to var(U)=var(V)=1); sparse CCA (adds an L1 penalty for high-dimensional tables); Constrained/"Canonical" Correspondence Analysis (CCpnA) forces CA axes to lie in the span of supplied environmental covariates — a middle ground between unsupervised ordination and full regression.
- Supplementary points/variables: project a batch, treatment, or other covariate's group-means onto an *already-fitted* PCA/MDS/CA space without letting it influence the decomposition — a powerful, non-distorting way to diagnose batch effects and confounding.

## Common mistakes / pitfalls
- Defaulting to Euclidean/L2 distance for count, compositional, or presence/absence data instead of assessing chi-square distance (CA) or another ecologically appropriate metric — L2 lets high-count features dominate and misrepresents co-occurrence structure.
- Running classical (metric) MDS when a few distances/samples are outliers: the squared-distance objective lets one extreme point dominate and skew the whole map. Prefer rank-based NMDS, or explicitly check robustness.
- Treating a single distance metric's ordination as definitive: on the same single-cell dataset, L1 distance gave 78% and L2 distance gave 57% of variance in the first two MDS axes — the same "2D map" claim means very different things depending on metric; always compare ≥2 metrics before trusting a low-dim picture.
- Reading an arch/horseshoe shape in an ordination plot as multiple discrete clusters (or dismissing it as a plotting artifact) rather than recognizing it as the classic signature of a single underlying 1D gradient (seriation, pseudotime, ecological gradient) that a global/linear method cannot "unfold" in 2D.
- Treating MDS/PCA/CA axis coordinates as having inferential meaning (implying a p-value or "significant axis") — ordination is exploratory/descriptive. Only dedicated tests (chi-square test for CA, Mantel/RV permutation tests for multi-table association) provide actual significance statements.
- Comparing axis signs/orientations of ordination maps across runs, samples, or software as if a flip were a real biological difference — MDS/PCoA solutions are only defined up to rotation/reflection.
- Skipping the omnibus test before drilling into a low-dimensional map: for a contingency table, verify non-independence with a chi-square test before computing/interpreting a CA; for two data tables, run an RV/Mantel permutation test before running CCA/sparse CCA/co-inertia and reporting "an association was found."
- Taking a high sparse-CCA/CCA correlation (e.g., 0.99) at face value when n is small and p or q is large (e.g., n=12 samples, hundreds of features): near-perfect correlation is close to guaranteed by having too many degrees of freedom, not evidence of real signal. The selected feature subset is a non-redundant explanatory set, not proven to be the "true" biological drivers.
- Running ordinary (non-regularized) CCA when p or q approaches or exceeds n — classical CCA requires X, Y full column rank with p ≤ n and q ≤ n; violate this (routine in omics) and the solution is unstable/overfit. Use sparse/regularized CCA instead.
- Letting two nuisance factors vary together with the factor of interest (confounding) — e.g., protocol AND array both changing between "day 1" and "day 2" batches — and then attributing the resulting PCA/ordination separation to the biological variable. No ordination or batch-correction method can disentangle fully confounded effects; the only fix is a deconfounding experiment (e.g., a third condition that decouples the two nuisance factors).
- Separating "metadata" (batch, day, protocol, treatment) from the assay matrix into a loosely-linked side table/file instead of a single tightly-bound container — risks losing the sample-to-covariate mapping, which can make later analyses impossible.
- Encoding a batch/categorical covariate as a bare numeric column appended to (or mixed into) the assay matrix rather than as an explicit factor/categorical variable — risks it silently being treated as continuous downstream.
- Only inspecting the first few eigenvalues of a classical MDS instead of the full spectrum — small but real negative eigenvalues are common and worth checking; a large-magnitude negative eigenvalue (relative to the top positive ones) signals the input dissimilarities are far from Euclidean-embeddable and low-dim coordinates should not be over-trusted.
- Plotting ordination axes (MDS, PCoA, PCA, CA, t-SNE) without a fixed/equal aspect ratio — since the axes jointly encode a distance, unequal scaling visually distorts the true relative distances/angles between points.
- Treating t-SNE inter-cluster distances, relative cluster sizes, or cluster "tightness" as quantitatively meaningful — t-SNE preserves local neighbor probabilities only; global spacing depends on the perplexity/σ parameter and local point density, and is not comparable across regions of a plot or across runs.
- Trusting a single t-SNE run (single perplexity) as ground truth — the method is not robust and can artificially separate or merge groups; vary perplexity/σ and check stability of qualitative conclusions.
- Running CA/MCA on a pre-aggregated cross-tabulation when the disaggregated (per-subject, long-format) data are available — cross-tabulating discards which specific individual carried which combination of categories, information that can matter downstream.
- Using raw ranks on low-abundance/near-noise-floor features as if rank differences among them were meaningful — near-zero measurements produce large, essentially arbitrary rank jumps; if using a rank transform for robustness, threshold/tie the bottom ranks together first (e.g., give all taxa below a chosen abundance rank the same tied score).
- Relying uncritically on the Mantel test for spatial/ecological distance-correlation claims without the caveats in the literature (e.g., Guillot & Rousset 2013, "Dismantling the Mantel Tests") — it can be anti-conservative or underpowered depending on the spatial/temporal autocorrelation structure of the units being compared.

## Assumptions to verify
- Classical MDS/PCoA assumes the input dissimilarities are (approximately) embeddable in real Euclidean coordinates — check the sign and magnitude of the eigenvalues.
- CA assumes the data are non-negative counts/frequencies forming a genuine contingency table with meaningful row/column marginal totals — chi-square distance is not meaningful for arbitrary continuous data.
- Classical CCA assumes p ≤ n, q ≤ n, and that X and Y have full column rank — routinely violated in multi-omics settings (p, q ≫ n), requiring sparse/regularized CCA.
- NMDS assumes only the rank order of the input dissimilarities is trustworthy, not their magnitude — appropriate when the measurement scale of the underlying distance is uncertain.
- t-SNE / local nonlinear embeddings assume the analysis goal is local neighborhood structure — inappropriate if global inter-group distances or relative spacing need to be interpreted.
- Diffusion maps / kernel MDS assume the chosen kernel bandwidth (σ) or perplexity meaningfully captures the local connectivity scale of the data — always check sensitivity to this parameter.
- The Mantel test assumes the compared distance matrices are permutation-exchangeable under the null, and its significance must be assessed via permutation (not a plug-in normal-theory p-value) precisely because distance-matrix entries are not independent of one another.
- A strong cross-table correlation from (sparse) CCA is assumed to reflect shared biological signal only if it survives an independent association test (RV/Mantel permutation) — otherwise high dimensionality alone can produce it.

## Diagnostic checks
- Plot the screeplot of eigenvalues (MDS, PCoA, CA, kernel MDS) and look for a steep drop; retain axes before the drop and report the % of total inertia/variance they capture.
- For NMDS: run many random restarts (e.g., ~100) per candidate dimensionality k, and boxplot the resulting stress values across k to pick a stable, low-stress k.
- Use a Shepard plot (original dissimilarity vs. reconstructed distance) to check the (N)MDS fit is not badly scattered.
- Inspect the FULL eigenvalue spectrum from classical MDS (not just the top few) and compare the magnitude of any negative eigenvalues to the largest positive ones.
- Run a chi-square test of independence (and/or inspect a mosaic plot of residuals) before running or interpreting a correspondence analysis on a contingency table.
- Run an RV coefficient permutation test (RV.test) or Mantel permutation test to confirm two tables/distance matrices are actually associated before doing CCA, sparse CCA, or co-inertia analysis.
- Recompute the ordination using ≥2 distance metrics (e.g., L1 vs. L2, Euclidean vs. chi-square) on the same data; large disagreement in % variance explained or embedding shape is itself informative, not a nuisance to be ignored.
- Color/facet ordination plots by every known technical covariate (batch, day, protocol, array, operator) with convex hulls or ellipses, and check whether the primary axes track a nuisance variable rather than (or in addition to) the biological factor of interest.
- If confounding is suspected, check whether a deconfounding sample set/design already exists (a group where the nuisance factors are decoupled); if not, flag that no ordination/statistical fix can substitute for it.
- After batch correction (e.g., ComBat/pyComBat), redo the ordination and confirm the batches now visually overlap/center near the origin, rather than assuming correction worked from the correction step alone.
- Vary t-SNE perplexity / diffusion-map σ / kernel bandwidth and check whether qualitative conclusions (number of clusters, gradient shape, branch structure) are stable across the range.

## Quick checklist
- [ ] Is the distance/dissimilarity metric appropriate for the data type (chi-square for counts/contingency tables; Euclidean/Manhattan for continuous; Jaccard/Bray–Curtis-type for presence–absence/compositional)? Was more than one metric tried and compared?
- [ ] Is a screeplot (or % inertia/variance table) shown, and does the number of retained/plotted axes match where the eigenvalues actually drop?
- [ ] If well under, say, 60% of variance/inertia is captured by the plotted 2D/3D embedding, is that limitation stated explicitly rather than left implicit?
- [ ] For contingency-table data, was a chi-square independence test run before correspondence analysis?
- [ ] For multi-table/multi-omics integration, was an omnibus association test (RV/Mantel) run before CCA/co-inertia/sparse CCA? If p or q is close to or larger than n, was a regularized/sparse method used instead of classical CCA?
- [ ] Are reported "axis"/"component" interpretations accompanied by an actual permutation/test-based p-value, or are they being read as statistically confirmed without one?
- [ ] Are known batch/protocol/array/day variables plotted as supplementary covariates to check for confounding, and if two nuisance variables coincide, is that confounding flagged rather than silently absorbed into "biological" axes?
- [ ] Is metadata (batch, treatment, timepoint) stored in the same container as the assay matrix (e.g., AnnData/SummarizedExperiment), not a loosely linked separate file?
- [ ] If using t-SNE/diffusion maps/kernel methods, was more than one perplexity/σ tried, and are inter-cluster distances/sizes explicitly not being over-interpreted?
- [ ] Are ordination plots drawn with a fixed/equal aspect ratio?
- [ ] If an arch/horseshoe pattern appears, has it been considered as evidence of a latent 1D gradient rather than dismissed or over-clustered?

## Key terms
- **Ordination** — dimensionality-reduction methods (PCA, MDS/PCoA, CA, NMDS, t-SNE, diffusion maps) used to visualize latent gradients or factors in low dimensions; the continuous-variable analog of clustering.
- **MDS / PCoA** (classical/metric multidimensional scaling, principal coordinates analysis) — reconstructs Euclidean coordinates from a distance matrix via double-centering + eigendecomposition. Python: `sklearn.manifold.MDS(metric=True)`, `skbio.stats.ordination.pcoa`.
- **NMDS** (non-metric MDS) — rank-based, robust ordination minimizing stress. Python approx.: `sklearn.manifold.MDS(metric=False)`.
- **Stress** — normalized sum-of-squares between reconstructed and (monotonically transformed) original distances; NMDS fit diagnostic.
- **Correspondence analysis (CA)** — chi-square-distance ordination for contingency tables with a symmetric, barycentric row/column biplot. Python: `prince.CA`.
- **Multiple correspondence analysis (MCA)** / **Multiple factor analysis (MFA)** — CA extended to several categorical variables, or a weighted analysis across several mixed-type tables so no one table dominates. Python: `prince.MCA`, `prince.MFA`.
- **Chi-square distance / inertia** — weighted distance measuring departure from independence in a contingency table; what CA decomposes (the analog of variance in PCA).
- **Confounding** — two or more explanatory factors vary together so their individual effects can't be statistically separated; fixable only by a deconfounding experimental design, not by post hoc modeling.
- **Supplementary point/variable** — a covariate or group mean projected onto an already-fitted ordination without influencing the fit; used to check for batch/treatment structure post hoc.
- **RV coefficient** — matrix-valued generalization of the correlation coefficient (range [0,1]) measuring association between two data tables.
- **Mantel coefficient/test** — correlation between two distance matrices, with significance assessed by permutation because distance-matrix entries are not independent. Python: `skbio.stats.distance.mantel`.
- **Canonical correlation analysis (CCA)** — linear combinations of two tables maximizing correlation; classical version requires n ≥ p, q. Python: `sklearn.cross_decomposition.CCA`.
- **Sparse CCA (sCCA)** — L1-penalized CCA for high-dimensional (p, q ≫ n) tables; a feature-screening tool, not a final inferential result.
- **Constrained/canonical correspondence analysis (CCpnA)** — CA whose axes are forced into the span of supplied environmental/explanatory covariates; between unsupervised ordination and full regression.
- **Diffusion map** — nonlinear embedding from Markov-chain transition probabilities between nearby points; recovers developmental trajectories/pseudotime. Python: `scanpy.tl.diffmap`.
- **t-SNE** — local, non-robust nonlinear embedding preserving neighbor probabilities; inter-cluster distances are not quantitatively comparable. Python: `sklearn.manifold.TSNE`.
- **Horseshoe/arch effect** — curved pattern in MDS/CA/PCA output typically indicating an underlying 1D gradient (pseudotime, ecological gradient), not discrete clusters.
- **Batch effect** — systematic nuisance variation tied to processing day/array/protocol; correctable (e.g., `ComBat`, `scanpy.pp.combat`) only when not fully confounded with the variable of interest.
- **Breakdown point** — fraction of data that can be corrupted before an estimator becomes arbitrarily wrong (median: 1/2; mean: 1/n); underlies why rank-based ordination is more robust than distance-squared-based ordination.
