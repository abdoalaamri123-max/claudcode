# 高频回应句式速查（中英对照）

> 按功能取用。句式是脚手架，内容必须贴合你的稿子。完整语境见 `references/11`。

## 致谢开场
| 中 | 英 |
| --- | --- |
| 感谢编辑与审稿人的细致与建设性意见 | We thank the Editor and reviewers for their careful and constructive comments. |
| 这些意见显著改进了本文 | These comments have substantially improved the manuscript. |

## 每条开头
| 中 | 英 |
| --- | --- |
| 感谢审稿人这一富有洞见的意见 | We thank the reviewer for this insightful comment. |
| 感谢指出这一重要问题 | We appreciate the reviewer raising this important point. |

## 同意并修改
| 中 | 英 |
| --- | --- |
| 我们同意并已据此修改（第x页） | We agree and have revised accordingly (p.x). |
| 遵照建议，我们新增了…… | Following the suggestion, we have added… |
| 补充分析后结论保持稳健 | The results remain robust after this additional analysis. |

## 部分同意
| 中 | 英 |
| --- | --- |
| 我们同意第一点；关于第二点，采取了不同处理，因为…… | We agree with the first point; regarding the second, we took a different approach because… |

## 礼貌反驳
| 中 | 英 |
| --- | --- |
| 我们理解这一关切，并作如下澄清 | We understand this concern and offer the following clarification. |
| 鉴于[理由]，我们认为当前做法是恰当的，同时乐于听从编辑意见 | Given [reason], we believe the current approach is appropriate, while remaining open to the editor's guidance. |
| 对X的完整分析超出本文范围，已列为未来研究 | A full analysis of X is beyond the scope of this study; we now note it as future work. |
| 原表述可能不够清楚，我们并非主张X，已重写该段 | Our original phrasing may have been unclear; we did not intend to claim X, and have rewritten the passage. |

## 承认局限
| 中 | 英 |
| --- | --- |
| 我们同意这是一处局限，并已明确讨论 | We agree this is a limitation and now discuss it explicitly. |

## 冲突审稿人
| 中 | 英 |
| --- | --- |
| 审稿人1建议X，审稿人2建议Y，我们通过……加以平衡 | R1 suggested X while R2 suggested Y; we balanced these by… |
| 若编辑倾向不同的平衡，我们乐于调整 | Should the editor prefer a different balance, we are happy to adjust. |

## 结尾
| 中 | 英 |
| --- | --- |
| 希望修改稿已解决全部关切 | We hope the revised manuscript addresses all concerns. |
| 再次感谢审稿人帮助我们改进本文 | We thank the reviewers again for helping us improve the paper. |

## ⚠️ 少用/慎用（易冒犯）
- ❌ "The reviewer is wrong / mistaken."
- ❌ "This is obvious / well known."
- ❌ "As we already stated…"（改为"we apologize this was not clear…"）
- ❌ 反问、感叹号泄愤、长篇辩解。
