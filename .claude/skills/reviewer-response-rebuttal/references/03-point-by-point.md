# 03 · 逐条回应的黄金三段式

> 每一条回应都用同一个结构。学会它，整封信就成型了。

## 一、黄金三段式

**① 复述意见（Restate）** → **② 说明修改（Respond）** → **③ 引用改后原文（Reproduce）**

```
【Comment R1.2】（原文照抄或忠实概述审稿人意见）
Response: 我们感谢这一意见。我们同意……，并做了如下修改：……
Revised text (p. 7, lines 12–18): "……改后的原文……"
```

## 二、三段各自要点

### ① 复述意见
- **照抄或忠实转述**审稿人原话，表明你**读懂了**。
- 不要曲解、缩水或断章取义（审稿人会核对）。

### ② 说明修改
- 先**表态**（感谢 / 同意 / 部分同意 / 说明）。
- 说清**你做了什么**：改了哪里、加了什么分析/文献/论证、为什么这样改。
- 语言具体，避免空泛的"已修改"。

### ③ 引用改后原文
- **把修改后的句子/段落贴出来**，标**页码/行号**。
- 让审稿人**不必翻原稿**就能核实。这是提高好感与效率的关键。
- 若改动很大（如新增一节），可摘录关键句 + 指路"详见 3.2 节"。

## 三、"具体"胜过"声称"

| ❌ 空泛 | ✅ 具体 |
| --- | --- |
| "已按建议修改。" | "我们在方法部分新增了稳健性检验（p.9, ll.4–15），结果与主分析一致，见新表 3。" |
| "已补充相关文献。" | "我们补充了 Smith (2021) 与 Lee (2022) 两项近期研究，并讨论了它们与本文的差异（p.3, ll.20–28）。" |

## 四、粒度：一条一答

- 一条意见含多个小问题时，**拆成 a/b/c 分别答**，不要合并。
- 审稿人的每个问号、每句"建议"都要有回应，哪怕答"已核对，确认无误，感谢指出"。

## 五、"未改但已回应"也要三段

即使你不采纳，也走三段式：复述→说明**为什么不改 / 如何以其他方式回应**（见 `06`）→若做了替代性说明，指出在文中何处。

## 六、常见误区
- ❌ 只写"Done / 已修改"，不贴改后原文、不给页行号。
- ❌ 曲解或压缩审稿人原意。
- ❌ 多个小问题合并成一段泛泛而答，遗漏其一。
- ❌ 回应里承诺改了，实际改稿里找不到（务必对齐，见 `10`）。
