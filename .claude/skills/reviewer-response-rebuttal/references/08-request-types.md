# 08 · 常见要求类型逐类应对

> 审稿意见虽千变万化，但大类就那么几种。认出类型，套对策略。

## 一、补充分析 / 稳健性检验
- **策略**：能做就做（补分析往往最能加分）。做完报告结果是否稳健、结论是否改变。
- **话术**："We have added [analysis] (p.x, Table y). Results are consistent with our main findings, indicating robustness."
- **做不了时**：说明数据/设计限制，提供最接近的替代分析或讨论。

## 二、补充文献
- **策略**：补上审稿人点名的 + 相关近作，**并说明它们与本文的关系/差异**，而非罗列。
- **话术**："We have incorporated [refs] and clarified how our study extends/differs from them (p.x)."
- **注意**：若审稿人在暗示引自己的文章，酌情引用相关者即可，无需谄媚堆砌。

## 三、理论深化 / 贡献不清
- **策略**：这是决定性意见。明确"理论缺口—本文如何填补—理论贡献"三段（可借 `ssci-writing` skill）。
- **话术**："We have sharpened our theoretical contribution by explicitly stating the gap (p.x) and how our findings advance [theory]."

## 四、方法 / 测量澄清
- **策略**：补方法细节、说明测量效度信度、澄清程序。若确有不足，承认并讨论局限。
- **话术**："We have added details on [sampling/measure/procedure] (p.x). Reliability was α = .xx…"

## 五、样本量 / 因果 / 内外效度质疑
- **策略**：这些常是核心质疑。
  - 样本量：报检验力分析/信息充分度论证；小样本的质性研究讲清取向逻辑。
  - 因果：横断面别硬称因果，讨论局限、建议纵向（见 `process` skill 的因果诚实）。
  - 概化：说明范围条件（scope conditions），不过度外推。
- **话术**："We acknowledge this limitation and now discuss it explicitly (p.x), while clarifying the scope conditions of our claims."

## 六、结构 / 表达 / 英语润色
- **策略**：照做。语言问题请母语者/专业润色，并在信中说明"the manuscript has been professionally edited for language."
- **话术**："We have restructured Section x for clarity and had the manuscript professionally proofread."

## 七、数据可得性 / 伦理 / 合规
- **策略**：补数据可得性声明、伦理批号、知情同意说明。技术性但不可漏（重投常卡在这）。

## 八、"我不理解你的贡献"（最危险）
- 这往往说明**你没讲清**，不是审稿人的错。回到引言与摘要，重述缺口与贡献；在 cover letter 里也强调。

## 九、类型 → 首步动作速查

| 类型 | 首步 |
| --- | --- |
| 补分析 | 评估可行性，能做就做并报稳健性 |
| 补文献 | 补相关近作 + 讲清关系 |
| 理论深化 | 重写缺口—填补—贡献三段 |
| 方法澄清 | 补细节/信效度，或承认局限 |
| 样本/因果 | 有据论证 + 讨论局限 + 限定范围 |
| 语言 | 专业润色并说明 |
| 合规 | 补声明，别漏 |
