# 07 · 审稿人意见冲突怎么办

> 两位审稿人要求相反（一个要你加、一个要你删；一个要更简、一个要更全），这很常见。处理原则：**摊开冲突、说明权衡、必要时请编辑定夺，别偷偷只听一个。**

## 一、第一步：明确指出冲突

不要假装没看见，也不要只回应其中一位。在相关条目里**明确点出两条意见的张力**：
> "We note that Reviewer 1 suggests expanding the theoretical framework, while Reviewer 2 recommends tightening the paper for concision. We have sought to balance these as follows…"

## 二、常见解决路径

| 路径 | 何时用 | 做法 |
| --- | --- | --- |
| **折中** | 两者都有合理内核 | 部分满足双方，如"加一段但精简别处" |
| **择优 + 说理** | 一方更契合研究目标/期刊定位 | 采纳一方，向另一方礼貌说明为何此处更宜如此 |
| **请编辑裁断** | 实质对立、无法两全 | 说明你的倾向与理由，明确请编辑定夺 |
| **技术性两全** | 形式冲突而非实质 | 如把详细内容移到附录，正文保持精简 |

## 三、把裁量权交给编辑（关键）

编辑就是仲裁者。冲突意见正是该用编辑的场合：
> "As these two suggestions point in different directions, we have chosen [X] because [reason], but we would be happy to follow the editor's preference."

这样既尊重两位审稿人，又不让自己被架在火上。

## 四、别做的事
- ❌ 只回应一位，对另一位的相反要求装作没看到。
- ❌ 两边都硬塞，结果稿子自相矛盾、臃肿。
- ❌ 让两位审稿人"隔空吵架"（引述一位来贬另一位）——只陈述你如何权衡。

## 五、语气
- 对两位都保持同等尊重与感谢。
- 描述冲突时中性、就事论事，不评判谁对谁错。

## 六、模板段
> "We thank both reviewers. Reviewer 1 (R1.4) suggested [A], whereas Reviewer 2 (R2.2) suggested [B]. Recognizing the value in both, we have [折中/择优方案], which we believe addresses the core concern behind each comment. Should the editor prefer a different balance, we are glad to adjust."
