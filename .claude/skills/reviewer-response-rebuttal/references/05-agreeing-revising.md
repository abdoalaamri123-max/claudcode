# 05 · 同意并修改：怎么写得到位

> 大多数意见你会接受。接受不等于随便写"已改"——要写得**具体、可核查、显得你真的动了脑**。

## 一、接受意见的标准写法

三段式（见 `03`）+ 具体：
> "**R2.3**: The reviewer suggests controlling for firm size.
> Response: We thank the reviewer for this suggestion. We agree that firm size may confound the relationship. We have added firm size (log total assets) as a control in all models. The results remain robust, and the main effect is unchanged.
> Revised text (p.10, ll.5–9): '…after controlling for firm size…'; see updated Table 3."

## 二、让"同意"更有分量

- **说明为什么这个修改让研究更好**（不只是"照办"）："This addition strengthens our identification by…"
- **报告修改带来的结果**：新分析结果是否稳健、结论是否变化——主动说清。
- **超额一点点**：审稿人要一个稳健性检验，你顺手补两个相关的，显得主动（但别偏离重点）。

## 三、"部分同意"怎么写

- 接受合理部分，说明你如何落实；对不适用部分，礼貌解释边界。
- "We agree with the first point and have revised accordingly (p.x). Regarding the second, …（说明为何以不同方式处理）"

## 四、避免"假改 / 口惠而实不至"

- **回应信说改了，改稿里必须真的有**，且页行号对得上（审稿人和编辑会抽查）。
- 别把"我们已在讨论中提及"当"已解决"——如果审稿人要的是实质分析，仅口头提及不够。
- 重投前用清单逐条核对回应与改稿一致（见 `10`）。

## 五、大改动的呈现

- 新增整节/整表：在回应里摘录关键句 + 指路，并在 cover letter 里点出这项大改进。
- 结构调整：用"we have reorganized Section 4 so that…"说明动机与效果。

## 六、常见误区
- ❌ "已修改"三个字打发。
- ❌ 回应承诺的改动在稿里找不到。
- ❌ 只在讨论里加一句就当补了分析。
- ❌ 改了却不报告"结果是否因此变化"。
