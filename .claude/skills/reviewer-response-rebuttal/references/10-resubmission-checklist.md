# 10 · 重投前核对与时间管理

> 回应信写完不等于能投。重投前要确保**回应信、修改稿、格式三者严丝合缝**，并管好截止时间。

## 一、回应—改稿一致性核对（最重要）

逐条过 `templates/point-by-point-table.md`：
- [ ] 每条意见都有回应（无遗漏）
- [ ] 回应里承诺的每个改动，**改稿里确实存在**
- [ ] 引用的**页码/行号与改稿一致**（改稿动过后页码会变，最后统一核对）
- [ ] "已在第 x 节新增"之类指路准确

> 最常见的重投翻车：回应信说改了，审稿人翻到那页发现没改或对不上号。

## 二、修改稿的两个版本

- **Tracked changes / 高亮版**：让审稿人一眼看到改动。多数期刊要求。
- **Clean 干净版**：接受后用。
- 检查投稿系统要求：有的要行号版、有的要合并 PDF。

## 三、格式与合规复查
- [ ] 期刊格式（字数、图表、参考文献样式）
- [ ] 伦理声明、数据可得性、利益冲突、作者贡献
- [ ] 补充材料（新表/新图/新分析代码）齐全
- [ ] 摘要/关键词若因修改而需更新

## 四、时间管理
- 看清截止日（major 常 30–90 天）。
- 工作量大 → **尽早礼貌申请延期**（多数编辑通融），别拖到最后一天硬交半成品。
- 留出**通稿时间**：让合作者/母语者审一遍回应信语气与英语。

## 五、重投前终检清单
- [ ] 逐条回应完整、三段式、有页行号
- [ ] cover letter 简短、突出主要改进
- [ ] 回应与改稿一一对应
- [ ] tracked + clean 两版齐全
- [ ] 格式/伦理/补充材料合规
- [ ] 语气通读无冒犯、无情绪、无错别字
- [ ] 所有文件按系统要求命名上传

## 六、常见退回原因（避雷）
- 漏答某条意见。
- 回应与改稿不符。
- 没提供标注修改版。
- 忽略编辑的硬性/格式要求。
- 语气冒犯审稿人。
