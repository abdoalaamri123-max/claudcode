# 08 · APA 报告与结果写作 / APA Reporting & Write-up

> 按 APA 7 规范报告统计结果。中英文论文通用，本文给出表格规范与中英结果句。

## 一、数值与符号规范 / Number & Symbol Conventions
- 统计符号**斜体**：M, SD, t, F, r, p, R², β, N, η²。
- **p 值**：报具体值（p = .03）；小于 .001 写 **p < .001**；不要写 p = .000。
- 小数：相关/p/β 等不可能 >1 的，**省略整数位 0**（.34 而非 0.34）；可>1 的保留（M=3.82）。一般保留 2 位，p 可 3 位。
- 报告**效应量与置信区间**，不仅是显著性。
- 自由度写在括号：t(298)=3.45；F(3, 296)=28.74；χ²(4, N=300)=12.3。

## 三、结果章节写作顺序 / Results Section Order
1. 数据清洗与样本描述（有效 N、剔除、人口学）
2. 共同方法偏差检验
3. 描述统计与相关矩阵
4. 信度与效度（α/CR/AVE/EFA 或 CFA 拟合）
5. 假设检验（差异/回归/SEM/中介调节，按假设编号 H1、H2…）
6. （可选）补充/稳健性分析

## 四、写作要点
- 每个假设明确说**支持/不支持**，对应数据。
- 先报整体（模型显著性/拟合），再报具体系数。
- 表与正文不重复堆砌；正文点出关键，细节放表。
- 图：中介/调节用路径图、简单斜率图；坐标轴与图注完整。
- 因果措辞谨慎：横断面相关数据用"预测/关联"，慎用"导致/影响"。

## 五、常见审稿雷点 / Common Reviewer Flags
- 只报 p 不报效应量与 CI。
- 未检验/报告前提假设（正态、共线、方差齐性、拟合）。
- p=.000、相关写成 0.34（应 .34）、效应量缺失。
- 共同方法偏差未处理（自评横断面）。
- 中介还在用 Baron-Kenny 逐步法而非 Bootstrap。
- SEM 只挑好看的拟合指数报。
- 自编量表无 EFA/CFA 证据就直接回归。
