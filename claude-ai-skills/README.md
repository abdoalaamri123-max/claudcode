# مهارات جاهزة للرفع إلى claude.ai

كل ملف ZIP هنا مهارة واحدة. ارفعها من: **Settings ← Capabilities ← Skills ← Upload skill**، ملفاً ملفاً.
فعّل أولاً **Code execution and file creation** من الصفحة نفسها، لأن بعض المهارات تشغّل سكربتات.

| الترتيب المقترح | المهارة | الاستخدام |
|---|---|---|
| 1 | `questionnaire-analysis` | الاستبانات: الصدق والثبات، EFA وCFA وSEM، الوساطة والتعديل |
| 2 | `statistical-consultant` | مستشار إحصائي يختار الاختبار ويفحص الافتراضات |
| 3 | `statistical-analysis` | الاختبارات الإحصائية وأحجام الأثر وتقارير APA |
| 4 | `statistical-power` | حجم العينة والقوة الإحصائية |
| 5 | `experimental-design` | تصميم الدراسة |
| 6 | `research-gap-finder` | الفجوة البحثية والفرضيات |
| 7 | `idea-novelty-auditor` | فحص أصالة الفكرة |
| 8 | `paper-lookup` | البحث في 18 قاعدة مفتوحة (OpenAlex، Crossref، PubMed، DOAJ...) |
| 9 | `literature-review` | مراجعة الأدبيات |
| 10 | `systematic-review` | المراجعة المنهجية PRISMA 2020 |
| 11 | `meta-analysis-systematic-review` | التحليل البعدي |
| 12 | `scientific-writing` | كتابة المخطوطة |
| 13 | `paper-argument-reconstructor` | بناء حجة الورقة (المقدمة، الملخص، المناقشة) |
| 14 | `manuscript-copyeditor` | التدقيق اللغوي الأكاديمي |
| 15 | `citation-auditor` | التحقق من المراجع والأوراق المسحوبة |
| 16 | `guideline-select` | اختيار إرشاد كتابة التقرير (CONSORT، STROBE...) |
| 17 | `journal-finder` | اقتراح مجلات مع التحقق من الفهرسة والربع |
| 18 | `journal-selector` | ترتيب المجلات المستهدفة والبدائل |
| 19 | `journal-scope-review` | توافق المخطوطة مع نطاق المجلة |
| 20 | `submission-screener` | فحص المخطوطة قبل الإرسال |
| 21 | `review-simulator` | محاكاة المحرر والمحكّمين |
| 22 | `cover-letter-writer` | خطاب التغطية |
| 23 | `revision-responder` | حزمة الرد على المحكّمين وخطاب الاعتراض |
| 24 | `reviewer-response-rebuttal` | الرد على المحكّمين نقطةً نقطة |

`all-skills.zip` يجمع الملفات الـ 24 للتنزيل مرة واحدة. فكّه أولاً، ثم ارفع كل ملف ZIP بداخله على حدة.

ملاحظة: اختُصر وصف مهارتَي `meta-analysis-systematic-review` و`reviewer-response-rebuttal` في هذه النسخ ليوافق حد الـ 1024 حرفاً في claude.ai.
